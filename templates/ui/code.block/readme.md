# CodeBlock

Kode multiline dengan pembungkusan baris opsional.

```tsx
import { CodeBlock } from '@templates/ui/code.block'
import '@templates/base.css'
import '@templates/ui/blocks.css'
```

Role, konfigurasi tema, native props/ref, aksesibilitas, override lokal, dan contoh tersedia di [Typography](../typography.md). Dokumentasi interaktif akan dibuat di aplikasi demo `preview/`, yang saat ini kosong.
