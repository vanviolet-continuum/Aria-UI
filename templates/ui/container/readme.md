# Container

Container full width secara default dengan lebar baca terpusat yang opt-in.

```tsx
import { Container } from '@templates/ui/container'
import '@templates/base.css'
import '@templates/ui/layout.css'
```

Stylesheet lengkap `templates/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Dokumentasi interaktif akan dibuat di aplikasi demo `preview/`, yang saat ini kosong.
