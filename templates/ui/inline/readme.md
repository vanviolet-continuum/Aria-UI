# Inline

Susunan horizontal, alignment center, dan wrap aktif untuk toolbar, badge, serta tombol.

```tsx
import { Inline } from '@templates/ui/inline'
import '@templates/base.css'
import '@templates/ui/layout.css'
```

Stylesheet lengkap `templates/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Dokumentasi interaktif tersedia di aplikasi demo preview/; source komponen tetap menjadi acuan API.
