# CodeText

Kode inline dengan peran code dan font monospace.

```tsx
import { CodeText } from '@templates/ui/code.text'
import '@templates/base.css'
import '@templates/ui/blocks.css'
```

Role, konfigurasi tema, native props/ref, aksesibilitas, override lokal, dan contoh tersedia di [Typography](../typography.md). Dokumentasi interaktif tersedia di aplikasi demo preview/; source komponen tetap menjadi acuan API.
