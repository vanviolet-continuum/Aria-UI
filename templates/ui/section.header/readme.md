# SectionHeader

Heading konsisten untuk panel, form, dan drawer.

```tsx
import { SectionHeader } from '@templates/ui/section.header'
import '@templates/base.css'
import '@templates/ui/blocks.css'
```

Stylesheet lengkap `templates/styles.css` sudah memuat style blok. Props, default, slotProps, part komposisi, aksesibilitas, dan contoh tersedia di [Reusable content blocks](../composition.md). Dokumentasi interaktif akan dibuat di aplikasi demo `preview/`, yang saat ini kosong.
