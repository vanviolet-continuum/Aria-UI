# Grid

Kolom responsive 1–12 atau auto-fit berdasarkan minItemWidth; gap mengikuti tema.

```tsx
import { Grid } from './template/ui/grid'
import './template/base.css'
import './template/ui/layout.css'
```

Stylesheet lengkap `template/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Preview interaktif ada di `/components?component=grid`.
