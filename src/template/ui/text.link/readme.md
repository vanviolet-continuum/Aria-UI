# TextLink

Link semantik dengan native props, focus, dan warna tema.

```tsx
import { TextLink } from './template/ui/text.link'
import './template/base.css'
import './template/ui/blocks.css'
```

Role, konfigurasi tema, native props/ref, aksesibilitas, override lokal, dan contoh tersedia di [Typography](../typography.md). Preview: `/components?component=text-link`.
