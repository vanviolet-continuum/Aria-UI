# FieldLabel

Label form dengan htmlFor, required marker, dan peran label dari tema.

```tsx
import { FieldLabel } from './template/ui/field.label'
import './template/base.css'
import './template/ui/blocks.css'
```

Role, konfigurasi tema, native props/ref, aksesibilitas, override lokal, dan contoh tersedia di [Typography](../typography.md). Preview: `/components?component=field-label`.
