# SectionHeader

Heading konsisten untuk panel, form, dan drawer.

```tsx
import { SectionHeader } from './template/ui/section.header'
import './template/base.css'
import './template/ui/blocks.css'
```

Stylesheet lengkap `template/styles.css` sudah memuat style blok. Props, default, slotProps, part komposisi, aksesibilitas, dan contoh tersedia di [Reusable content blocks](../composition.md). Preview interaktif: `/components?component=section-header`.
