# Box

Surface semantik, padding, radius, border, shadow, warna, dan ukuran dari token tema.

```tsx
import { Box } from './template/ui/box'
import './template/base.css'
import './template/ui/layout.css'
```

Stylesheet lengkap `template/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Preview interaktif ada di `/components?component=box`.
