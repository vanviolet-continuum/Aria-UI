# Card

Panel dengan varian tema dan part CardHeader/CardBody/CardFooter.

```tsx
import { Card } from './template/ui/card'
import './template/base.css'
import './template/ui/blocks.css'
```

Stylesheet lengkap `template/styles.css` sudah memuat style blok. Props, default, slotProps, part komposisi, aksesibilitas, dan contoh tersedia di [Reusable content blocks](../composition.md). Preview interaktif: `/components?component=card`.
