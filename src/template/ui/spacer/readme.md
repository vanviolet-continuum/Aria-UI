# Spacer

Jarak dekoratif responsive atau ruang fleksibel dengan grow.

```tsx
import { Spacer } from './template/ui/spacer'
import './template/base.css'
import './template/ui/layout.css'
```

Stylesheet lengkap `template/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Preview interaktif ada di `/components?component=spacer`.
