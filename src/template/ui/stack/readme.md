# Stack

Susunan vertikal/horizontal dengan direction, gap, align, justify, dan wrap yang responsive.

```tsx
import { Stack } from './template/ui/stack'
import './template/base.css'
import './template/ui/layout.css'
```

Stylesheet lengkap `template/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Preview interaktif ada di `/components?component=stack`.
