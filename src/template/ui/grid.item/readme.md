# GridItem

Rentang kolom/baris responsive, self alignment, dan order di dalam Grid.

```tsx
import { GridItem } from './template/ui/grid.item'
import './template/base.css'
import './template/ui/layout.css'
```

Stylesheet lengkap `template/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Preview interaktif ada di `/components?component=grid-item`.
