# Toolbar

Kelompok kontrol dengan ToolbarGroup dan ToolbarActions, tanpa state bisnis.

```tsx
import { Toolbar } from './template/ui/toolbar'
import './template/base.css'
import './template/ui/blocks.css'
```

Stylesheet lengkap `template/styles.css` sudah memuat style blok. Props, default, slotProps, part komposisi, aksesibilitas, dan contoh tersedia di [Reusable content blocks](../composition.md). Preview interaktif: `/components?component=toolbar`.
