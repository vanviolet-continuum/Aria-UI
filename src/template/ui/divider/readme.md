# Divider

Separator horizontal/vertikal dengan spacing dan inset dari token tema.

```tsx
import { Divider } from './template/ui/divider'
import './template/base.css'
import './template/ui/layout.css'
```

Stylesheet lengkap `template/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Preview interaktif ada di `/components?component=divider`.
