# Koleksi tambahan SVG

Ilustrasi objek dan lingkungan tanpa figur manusia. Setiap SVG memakai komposisi lapang, garis membulat 1.8, serta token warna tema. Semua komponen menerima `IllustrationProps`: `size`, `tone`, `title`, `className`, dan `style`. Tanpa judul, gambar disembunyikan dari screen reader.

Komponen diekspor dari `@/template/ui/illustrations`, `@/template/ui`, serta `@/template`. Impor stylesheet kit seperti biasa. Galeri menyediakan salin komponen, salin SVG, dan unduh SVG dengan warna tema saat ini.
