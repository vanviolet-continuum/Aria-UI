# Container

Container full width secara default dengan lebar baca terpusat yang opt-in.

```tsx
import { Container } from './template/ui/container'
import './template/base.css'
import './template/ui/layout.css'
```

Stylesheet lengkap `template/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Preview interaktif ada di `/components?component=container`.
