# CodeBlock

Kode multiline dengan pembungkusan baris opsional.

```tsx
import { CodeBlock } from './template/ui/code.block'
import './template/base.css'
import './template/ui/blocks.css'
```

Role, konfigurasi tema, native props/ref, aksesibilitas, override lokal, dan contoh tersedia di [Typography](../typography.md). Preview: `/components?component=code-block`.
