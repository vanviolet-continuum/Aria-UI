# PageHeader

Header halaman dengan props praktis atau komposisi part terpisah.

```tsx
import { PageHeader } from './template/ui/page.header'
import './template/base.css'
import './template/ui/blocks.css'
```

Stylesheet lengkap `template/styles.css` sudah memuat style blok. Props, default, slotProps, part komposisi, aksesibilitas, dan contoh tersedia di [Reusable content blocks](../composition.md). Preview interaktif: `/components?component=page-header`.
