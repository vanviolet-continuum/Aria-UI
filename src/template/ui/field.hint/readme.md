# FieldHint

Petunjuk input dengan peran helper dan dukungan aria-describedby.

```tsx

import './template/base.css'
import './template/ui/blocks.css'
```

Role, konfigurasi tema, native props/ref, aksesibilitas, override lokal, dan contoh tersedia di [Typography](../typography.md). Preview: `/components?component=field-hint`.
