# Inline

Susunan horizontal, alignment center, dan wrap aktif untuk toolbar, badge, serta tombol.

```tsx
import { Inline } from './template/ui/inline'
import './template/base.css'
import './template/ui/layout.css'
```

Stylesheet lengkap `template/styles.css` sudah menyertakan style layout. API, breakpoint, spacing scale, konfigurasi tema, dan contoh komposisi tersedia di [Layout foundations](../layout.md). Preview interaktif ada di `/components?component=inline`.
