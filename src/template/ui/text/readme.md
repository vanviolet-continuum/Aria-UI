# Text

Teks presentasional dengan variant semantik yang dikonfigurasi melalui tema.

```tsx
import { Text } from './template/ui/text'
import './template/base.css'
import './template/ui/blocks.css'
```

Role, konfigurasi tema, native props/ref, aksesibilitas, override lokal, dan contoh tersedia di [Typography](../typography.md). Preview: `/components?component=text`.
