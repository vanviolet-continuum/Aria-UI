# Copy dan locale

Acuan: [panduan i18n](../../../../templates/i18n/readme.md), [factory instance](../../../../templates/i18n/create.i18n.ts), dan [config starter](../../../../src/config/i18n.config.ts).

- Copy bisnis/menu/halaman: `src/locales/id.json` dan `src/locales/en.json`.
- Copy umum milik kit: `templates/i18n/locales/id/ui.json` dan `templates/i18n/locales/en/ui.json`.
- Locale demo dimiliki `preview/src/locales/` dan digabung pada [config demo](../../../../preview/src/config/i18n.config.ts); starter tidak mengimpornya.

Instance aplikasi dibuat sekali melalui `createTemplateI18n({ resources })`, lalu diteruskan ke `TemplateProvider`. Default Bahasa Indonesia dengan English tersedia. Resource namespace aplikasi adalah `app`, dengan fallback copy kit `ui`.

```tsx
import { useI18n } from '@templates/i18n'

const { t, locale } = useI18n()
const heading = t('Welcome to {{name}}.', { name: workspace.name })
```

Gunakan key stabil dan interpolasi untuk kalimat dinamis. Isi terjemahan ID/EN bersamaan. Data pengguna, ID, enum API, SKU, dan nilai form tetap mentah; terjemahkan label yang ditampilkan, bukan nilai penyimpanan/API.

`text(value)` membantu komponen menerima string atau ReactNode. Untuk tanggal/angka gunakan locale aktif. Tanggal picker berupa local date `YYYY-MM-DD`, rentang `{ from?: string; to?: string }`, waktu `HH:mm`, dan date-time lokal `YYYY-MM-DDTHH:mm`; perubahan bahasa tidak mengonversi tanggal ke UTC atau mengganti mata uang.

Gunakan `Field` dan komponen label/error bawaan agar terjemahan tidak menghilangkan hubungan `htmlFor`, ID, dan `aria-describedby`.

Pesan backend merupakan display text API dan tidak melewati t/text. Field dengan error API menggunakan errorSource api; adapter form mempertahankan sumber pesan. Pesan validasi Zod lokal dan fallback teknis ketika API tidak menyediakan pesan tetap dapat diterjemahkan.
